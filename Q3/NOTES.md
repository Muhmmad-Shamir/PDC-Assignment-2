When I ran the program, it showed the main thread first. Both Log-Worker and Telemetry-Worker completed five iterations. The log worker printed the simulated log counts, and the telemetry worker showed CPU usage and memory information. Three log updates appeared before the first telemetry update. After that, their outputs appeared between each other because both workers were running concurrently. At the end, both thread states were TERMINATED, and the program printed “Both workers completed.”
